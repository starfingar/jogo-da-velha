# Jogo da Velha

O clássico Jogo da Velha, desenvolvida com tecnologias web padrão.

## Demonstração

O projeto está publicado e pode ser testado diretamente no seu navegador:

[Acessar a aplicação](https://starfingar.github.io/jogo-da-velha)

## Tecnologias

* HTML
* CSS
* JavaScript

## Como executar o projeto localmente

1. Clone este repositório para a sua máquina local:
   ```bash
   git clone https://github.com/starfingar/jogo-da-velha.git
   ```

2. Navegue até a pasta do projeto:
   ```bash
   cd jogo-da-velha
   ```

3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
